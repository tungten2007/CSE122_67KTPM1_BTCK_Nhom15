# Inter dùng trong CreatorStudio

Nguồn chính thức: The Inter Project, release **v4.1**; Git commit `e3a3d4c57d5ecc01453a575621882a384c1995a3`. Hai tệp WOFF2 được giữ nguyên từ `docs/font-files/` trong repository `rsms/inter`, tải qua HTTPS có xác minh TLS.

Giấy phép SIL Open Font License 1.1 được giữ ở `LICENSE-Inter.txt`. Các tệp đầy đủ có cả ký tự Latin, tiếng Việt và dấu kết hợp; dải độ đậm 100–900. Không chia unicode-range thành nhiều font để tránh fallback khác phông khi dùng chữ Unicode dạng tách dấu.

Font được phục vụ cùng website, không gọi Google Fonts/CDN khi người dùng mở trang. CSS dùng font-display swap và có Segoe UI/Arial dự phòng.
