# CreatorStudio — thư mục chạy website

Tài liệu tổng thể và 15 phần báo cáo nằm tại [README gốc](../README.md). Danh mục tài liệu: [docs/README](docs/README.md).

Mở thư mục này bằng VS Code, chạy [html/sv1/index.html](html/sv1/index.html) với Live Server. Hoặc chạy `python server.py 8000` rồi mở http://127.0.0.1:8000/html/sv1/index.html.

HTML/CSS/JS chia theo sv1, sv2, sv3; mã chung ở shared. Chọn vai trò và tài khoản cụ thể trên trang đăng nhập. Dữ liệu demo lưu theo origin trong LocalStorage, không tự thay dữ liệu cũ khi cập nhật code.

[Kết quả kiểm tra và giới hạn](docs/01-gatekeeper/evidence-index.md). Quy trình thay đổi: local → feature/sv3 → kiểm tra → dev → đồng bộ local. Chưa quay video.
