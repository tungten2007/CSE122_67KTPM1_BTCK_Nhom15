CREATORSTUDIO · PHẦN SV3

Mở website và gửi cho bạn cùng nhóm

Bộ này gồm 6 màn hình SV3 và khung điều hướng dùng chung. Các vai trò Khách hàng/Nhà thiết kế đang chờ ghép phần SV1/SV2.

1. Giải nén đầy đủ

Bấm phải ZIP → Extract All (Giải nén tất cả). Trong thư mục phải có các file HTML và các thư mục css, js, assets.

Gửi nguyên CreatorStudio-SV3-Website.zip. Gửi riêng 3 file HTML sẽ thiếu CSS, JavaScript và ảnh.

2. Chạy bằng VS Code

  1. File → Open Folder → chọn thư mục đã giải nén.
  2. Bấm phải index.html → Open with Live Server.
  3. Đổi vai trò ở đầu trang để mở Trưởng nhóm hoặc Quản trị viên.

Nếu máy có Python 3.9 trở lên, có thể bấm CHAY-WINDOWS.bat. Máy chủ sẽ kiểm tra file trước khi mở trình duyệt.

Mở bản demo

Nút trên phù hợp khi trang này cũng đang mở qua Live Server. Mở bằng cách bấm đúp HTML chỉ nên dùng xem nhanh; lưu dữ liệu giữa các trang có thể khác nhau tùy trình duyệt.

3. Nếu vẫn chỉ thấy “Đang mở…”

  • Giải nén lại toàn bộ ZIP; không đổi tên hoặc di chuyển riêng các thư mục con.
  • Kiểm tra hộp thông báo thiếu file ở đầu trang.
  • Nếu có Python, chạy python check_bundle.py để biết chính xác file nào thiếu.
  • Mở index.html trước. Trang quản trị có kiểm tra vai trò; nếu thấy 403, đổi sang Quản trị viên.

4. Dữ liệu trên máy khác

Máy khác khởi đầu bằng dữ liệu mẫu. Thay đổi bạn lưu trên máy mình không tự nằm trong ZIP. Nút “Xuất dữ liệu JSON” dùng để lưu bản sao; bản hiện tại chưa có chức năng nhập bản sao.

Xem hướng dẫn Task 5 và checklist trong thư mục docs. Website chưa được xuất bản công khai.
