Tên thật/GitHub, deadline, task Trello, commit, PR, người review và OBS chưa được cung cấp. Nhánh trên là đề xuất, không phải nhánh đã tồn tại.

Quy trình: task → nhánh feature → commit có ý nghĩa → push → PR → review chéo → merge dev → test tích hợp → PR lên main. Không sửa trực tiếp main. Chưa có .git trong thư mục được kiểm tra; chưa có bằng chứng lịch sử Git hoặc repo chung.

Mỗi thành viên cần tự thực hiện luồng Mockup → HTML → CSS → JS → Data → Responsive → Branch → Commit → PR → OBS. Không tạo commit/OBS giả để đánh dấu hoàn thành.
