Nhật ký HTTP

Mỗi thao tác ghi lại phương thức, mã HTTP, thời gian và JSON trả về. Mở F12 → Network để quan sát request thật.

    Kịch bản demo nhanh

    1. Chọn Tải từ API: nhận danh sách với mã 200.
    2. Tạo một dự án: POST trả 201; mở tab thứ hai để thấy cùng dữ liệu máy chủ.
    3. Sửa dự án: PATCH trả 200. Hai tab sửa cùng bản sẽ nhận 412 ở tab dùng revision cũ.
    4. Trong biểu mẫu, tích Thử lỗi 503 ở lần lưu này rồi lưu: hộp thoại giữ nội dung để bạn thử lại.
    5. Xóa dự án thử: DELETE trả 204. Tải lại trang để kiểm tra.

    Chạy: python server.py 8000 --open. Live Server vẫn mở được bài frontend cũ nhưng không cung cấp các route API này. Mock API chưa có xác thực hoặc phân quyền backend; server chỉ lắng nghe trên 127.0.0.1.
